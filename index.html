Surface Book 3は「保留」

性能が低いからではない。 32GB RAMとGeForce GTX 1650搭載モデルは、ブラウザ・AIツールの同時利用や軽いゲームで明確なメリットがある。一方、中古で約5.4万円を出す場合は、タブレット側とベース側のバッテリー、着脱機構、キーボードベース内GPUなど、一般的な法人ノートより構造が複雑で、故障時のリスクを織り込む必要がある。

13.5インチ Core i7モデルには32GB / 512GB / GTX 1650 Max-Q構成が存在。Microsoft公式仕様で確認済み。

中古法人PCで必ず確認する項目

スペック表だけでは見抜けない、購入後トラブルになりやすい部分。

  • BIOS / UEFIパスワードが解除済みか
  • Windows Autopilotや企業管理が残っていないか
  • Windows 11のライセンス状態
  • SSDの健康状態・総書き込み量
  • バッテリー劣化率・膨張の有無
  • USB-C充電・映像出力が正常か
  • 液晶の白ムラ・輝度ムラ・ドット抜け
  • ACアダプター付属と純正/適合ワット数
  • メモリ構成が1枚か2枚か、空きスロット有無
  • 販売店保証・初期不良対応期間
